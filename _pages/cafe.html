01 / OVERVIEW

Task formulation belongs
inside the autonomy loop.

Most embodied systems start with a human-provided goal. CAFE starts with an evolving scene state.

CAFE is a closed-loop embodied framework for autonomous task formulation and execution. During exploration, the robot maintains a structured semantic memory of objects, functional zones, and their changing states. A lightweight Trigger-LLM evaluates when actionable opportunities warrant further reasoning. A staged Draft–Complete–Audit pipeline then turns those opportunities into grounded action sequences.

Execution outcomes are written back into the shared memory, supporting task correction and replanning as the environment changes. The framework is evaluated in AI2-THOR and on a physical LimoCobot across task discovery, constraint satisfaction, step completeness, and execution.

What “without explicit task input” means

The robot receives a fixed task-category prior covering cleaning, safety, and storage/organization. It is not given a scene-specific task list or step-by-step instructions. Available action primitives and structured perception remain part of the system.

02 / FRAMEWORK

Observe. Formulate. Execute. Update.

Shared semantic memory connects task discovery, staged reasoning, and execution feedback.

A

Semantic memory

Track object states, functional zones, and scene changes during exploration.

B

Draft · Complete · Audit

Propose tasks, expand executable steps, and resolve constraints before execution.

C

Feedback-driven execution

Write outcomes back into memory and revisit incomplete tasks when needed.

05 / REAL-WORLD VALIDATION

From simulation to a physical robot.

LimoCobot demonstrations cover key storage, trash disposal, prioritized cleanup, and corrective re-execution after a manipulation failure.

Simple scenario

Pick up and store a dropped key, then collect scattered trash and dispose of it in the bin.

Complex scenario

Prioritize the spilled water, then handle two pieces of trash and a misplaced roll of tape.

Corrective retry

After a failed grasp, feedback identifies the incomplete disposal task and triggers re-execution.

06 / DISCUSSION

What remains open.

The framework relies on structured scene-state representations, so perception errors can propagate into task formulation. Execution still depends on the reliability of low-level controllers and skill primitives. Current experiments focus on a single robot; multi-agent and human–robot collaboration remain future directions.

The hardware results demonstrate example behaviors on LimoCobot. They do not establish large-scale, long-term deployment reliability.
